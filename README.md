# Bookstore Database Project

A MySQL relational database design project for managing bookstore operations.

## 📁 Structure
- `schema/` – SQL scripts to create all tables
- `inserts/` – Sample data inserts
- `users/` – User roles and access control
- `queries/` – Example SELECT queries
- `diagrams/` – ERD (Draw.io format)

## 🛠️ Tools Used
- MySQL
- Draw.io
- GitHub

## ✅ Features
- Books, authors, publishers, customers, orders, and shipping
- Many-to-many and one-to-many relationships
- Role-based access control
